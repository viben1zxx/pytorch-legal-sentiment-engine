# ⚖️ PyTorch Legal Sentiment & Risk Analysis Engine

## 📌 Project Overview
The Legal Sentiment Engine is a domain-adapted Natural Language Processing (NLP) tool built with PyTorch. It evaluates legal documents, court filings, and contracts to classify sentiment tone, identify compliance nuances, and score contractual risk factors.

## ✨ Key Capabilities
* **Domain-Adapted NLP:** Specialized text processing tailored for complex legal syntax and regulatory terminology.
* **Multi-Class Risk & Sentiment Scoring:** Categorizes text blocks by risk level (Low, Medium, High) and semantic tone.
* **Batch Document Ingestion:** Supports automated parsing and scoring across multi-page legal corpora.
* **Evaluation Metrics:** Built-in validation pipelines tracking Precision, Recall, and F1-score across legal datasets.

## 🛠️ Technology Stack
* **Core Framework:** PyTorch 2.x
* **NLP Tools:** Transformers, NLTK
* **Data Processing:** Pandas, NumPy, Scikit-learn
* **Language:** Python 3.11
